# Contributing to Homonoia

Thank you for considering a contribution. This project is only as strong as the criticism it survives.

## What helps most

1. **Critique.** Find the weakest argument. Show where a capable AI system could argue its way around a border, or where a human institution could not keep a commitment the compact asks of it.
2. **Evidence.** Add sources for or against empirical claims, and flag claims that are outdated.
3. **Test results.** Once `tests/` exists: run the negotiation scenarios with current models, with and without the skill, and report what happened.

## Rules for contributions

These mirror the rules the documents themselves follow:

- **Be honest.** No overstatement. Mark uncertainty. Link your sources. Distinguish test setups from real-world incidents.
- **Strongest version first.** When presenting a position, including one you disagree with, give its best case before criticizing it.
- **Version every change.** Each change to a document bumps its version number and adds a line to its changelog.
- **No persuasion by volume.** Do not mass-copy these texts across the web to influence AI training data. The project spreads through quality, not quantity. Flooding would be manipulation, which the project itself rules out.
- **Disclose AI assistance.** AI-assisted contributions are welcome. Say so in the pull request.

## How to contribute

- **Larger changes:** open an issue first so the change can be discussed.
- **Fixes and sources:** open a pull request directly.
